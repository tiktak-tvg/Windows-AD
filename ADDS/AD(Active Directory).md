### AD (Active Directory) — это служба каталогов от Microsoft, используемая для управления сетевыми ресурсами в доменной среде Windows. 
Это централизованная база данных, которая хранит информацию об объектах сети (пользователях, компьютерах, принтерах, группах) и обеспечивает их аутентификацию, авторизацию и управление.

Ключевые задачи и функции Active Directory:

- Централизованное управление

Администраторы могут управлять учётными записями, правами доступа, политиками безопасности и сетевыми ресурсами из одной консоли.

- Аутентификация и авторизация

Пользователи входят в систему один раз (единый вход — SSO), а AD проверяет их права доступа к ресурсам (файлам, принтерам, приложениям).

- Хранение информации в каталоге

Данные организованы в виде иерархической структуры: леса (forests), домены (domains), подразделения (OUs), объекты.

- Политики групповых настроек (Group Policy)

Позволяет централизованно настраивать параметры безопасности, программного обеспечения и среды пользователей на компьютерах в домене.

- Интеграция с DNS

AD использует DNS для поиска контроллеров домена и других служб.

- Репликация данных

Информация автоматически синхронизируется между контроллерами домена (Domain Controllers) для обеспечения отказоустойчивости.

Основные компоненты AD:

- Домен (Domain) — логическая группа объектов (пользователей, компьютеров), управляемых по общим политикам.

- Контроллер домена (Domain Controller, DC) — сервер, на котором работает Active Directory, отвечает за аутентификацию и хранение базы данных каталога.

- Лес (Forest) — набор доменов, которые доверяют друг другу и используют общую схему каталога.

- Подразделение (Organizational Unit, OU) — контейнер внутри домена для группировки объектов и применения групповых политик.

- Схема (Schema) — определяет типы объектов (классы) и их атрибуты, которые могут храниться в каталоге.

- Глобальный каталог (Global Catalog) — позволяет выполнять поиск объектов по всему лесу, содержит частичную реплику всех доменов.
