### Active Directory Domain Services (ADDS) обычно включает в себя следующие основные службы и роли (некоторые из них можно рассматривать как отдельные службы в составе ADDS):

Основные службы/роли ADDS:

- Доменные службы Active Directory (AD DS) — ядро, обеспечивающее:

- Аутентификацию и авторизацию (Kerberos, NTLM).

- Централизованное управление объектами (пользователи, компьютеры, группы).

- Репликацию данных между контроллерами домена.

- Служба DNS — тесно интегрирована с ADDS для разрешения имён и локализации контроллеров домена.

- Служба каталогов (Directory Service) — хранение и предоставление данных каталога.

- Служба репликации (NTDS) — отвечает за репликацию данных между контроллерами домена.

- Служба Kerberos Key Distribution Center (KDC) — часть службы Kerberos для безопасной аутентификации.

- Служба центра сертификации (Active Directory Certificate Services, AD CS) — часто развёртывается отдельно, но тесно связана с инфраструктурой AD.

- Служба федерации (Active Directory Federation Services, AD FS) — для единого входа (SSO) в распределённых системах.

- Служба управления правами (Active Directory Rights Management Services, AD RMS) — защита документов.

- Lightweight Directory Services (AD LDS) — облегчённая версия ADDS для сценариев без развёртывания домена.

В узком смысле (базовый ADDS):

Если рассматривать только ядро ADDS, то обычно выделяют:

- Службу каталогов (NTDS).

- Службу репликации.

- Службу Kerberos.

Интегрированную службу DNS.

> Итого:
> - В расширенном понимании ADDS включает до 9+ связанных служб (AD DS, DNS, AD CS, AD FS, AD RMS, AD LDS и т.д.).
> - В базовом развёртывании — 3-4 ключевые службы (каталог, репликация, аутентификация, DNS).

Точное число зависит от контекста: простой домен Windows Server включает минимум 3-4 службы, а полноценная инфраструктура предприятия — до 10 и более.
