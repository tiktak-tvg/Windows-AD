Проверка доступности контроллера домена
Убедитесь, что контроллер домена DC-01 вообще доступен и функционирует.

Проверьте, отвечает ли он по сети: ping DC-01.moscow.local

Проверьте, запущены ли на нём ключевые службы: Запустите оснастку services.msc на DC-01 и убедитесь, что работают:

Netlogon
DNS Server (если он является DNS-сервером)
Active Directory Domain Services

Проверьте, виден ли он в оснастке "Active Directory пользователи и компьютеры": Разверните ветку Domain Controllers – там должен быть компьютерный объект для DC-01.

Попробуйте прореплицировать данные НА проблемный сервер: repadmin /replicate srv2-DC DC-01 DC=moscow,DC=local

Для проверки состояния репликации между контроллерами в домене используется встроенная утилита repadmin. Базовая команда проверки входящей и исходящей репликации:
repadmin /replsum

Утилита вернет текущий статус репликации между всеми DC. В идеальном случае значение largest delta не должно превышать 1 час (зависит от топологии и настроек частоты межсайтовых репликаций), а количество ошибок replication fails = 0. В моем примере видно, что одна из последних репликаций заняла 14 дней, но сейчас все OK.

Чтобы выполнить проверку репликации для всех DC в домене:

repadmin /replsum *

Проверка межсайтовой репликации:

repadmin /showism

Для просмотра топологии репликации и найденных ошибках, выполните:

repadmin /showrepl

Для вывода расширенной информации, используйте:
repadmin /showrepl *

Для запуска принудительной синхронизации указанного DC со всеми партнерами по репликации, используйте команду

repadmin /syncall

Если нужно принудительно заставить контроллер домена получить изменения с других DC, исопльзуется команда:

repadmin /syncall /Ade

Для просмотра очереди репликации:

replmon /syncall <nameDC>

Для просмотра очереди репликации:

repadmin /queue

Проверьте время создания последней резервной копии текущего контроллера домена:

Repadmin /showbackup *

Это более общая команда, которая заставляет целевой сервер синхронизироваться со всеми своими партнерами по репликации для всех разделов.

cmd
repadmin /syncall /A /e /P
Расшифровка ключей:

/A — синхронизировать все разделы AD (Domain, Config, Schema).

/e — синхронизироваться со всеми партнерами по репликации (межсайтовыми в том числе).

/P — приостановить запрос на выполнение команды, если какой-либо из партнеров недоступен.

Просто выполните эту команду на том контроллере домена, который должен получить актуальные данные.
