#### Использование GPO для безопасности и комплаенса
Системные администраторы используют GPO как инструмент для соблюдения стандартов безопасности (например, ISO 27001 или внутренних регламентов): 

- Управление учетными записями:
  - Настройка политик сложности и срока действия паролей.
- Ограничение прав локальных администраторов (принцип наименьших привилегий).
- Блокировка учетных записей после нескольких неудачных попыток входа.
- Защита рабочих станций:
  - AppLocker / Software Restriction Policies: запрет запуска любого ПО, кроме разрешенного (белые списки).
  - Отключение USB-накопителей для предотвращения утечек данных и заноса вирусов.
  - Принудительное включение брандмауэра Windows и BitLocker для шифрования дисков.
- Использование Baseline (Базовых настроек):
  - Применение «Microsoft Security Baselines» — готовых наборов настроек от Microsoft, которые считаются эталонными для защиты ОС в 2025–2026 годах.
  - Использование инструментов вроде Policy Analyzer для сравнения текущих политик с рекомендуемыми стандартами комплаенса.
- Автоматизация и аудит:
  - Настройка расширенного аудита (Logon/Logoff, доступ к файлам) для последующего анализа в SIEM-системах.
  - Регулярное резервное копирование и версионность GPO с помощью AGPM (Advanced Group Policy Management) для быстрого отката изменений.
