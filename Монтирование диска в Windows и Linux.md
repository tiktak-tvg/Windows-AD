# Монтирование диска в Windows и Linux
Монтирование диска — это процесс подключения раздела диска или внешнего накопителя к файловой системе операционной системы, после чего его содержимое становится доступным для работы в выбранной папке (точке монтирования). Этот процесс отличается в зависимости от операционной системы.

Ниже приведены ключевые сведения для двух наиболее распространенных систем.

### 🖥️ Монтирование в Windows
В Windows для монтирования диска в папку (назначения точки монтирования) используются специальные системные средства. Основное требование — папка должна быть **пустой** и находиться на диске с файловой системой **NTFS или ReFS**.

*   **Основной метод**: **Управление дисками** (`diskmgmt.msc`).
    1.  Запустите "Управление дисками" от имени администратора.
    2.  Кликните правой кнопкой мыши на нужном разделе (томе) и выберите **"Изменить букву диска и пути"**.
    3.  Нажмите **"Добавить"**, затем выберите **"Подключить в следующую пустую папку NTFS"** и укажите путь к папке.

### 🐧 Монтирование в Linux
В Linux монтирование выполняется с помощью командной строки. Чаще всего для этого используется команда `mount`.

*   **Основная команда**: `sudo mount [опции] <устройство> <точка_монтирования>`
    *   **`<устройство>`**: путь к устройству (например, `/dev/sdb1`).
    *   **`<точка_монтирования>`**: путь к **существующей пустой папке** (например, `/mnt/mydisk`). Создать её можно командой `sudo mkdir`.
*   **Ключевые опции `mount`**:
    *   **`-t <тип_фс>`**: Указание типа файловой системы (например, `ext4`, `ntfs`, `vfat`).
    *   **`-r`**: Монтирование только для чтения.
    *   **`-o`**: Дополнительные параметры (например, `defaults`, `rw`).
*   **Автоматическое монтирование**: Для автоматического монтирования диска при загрузке нужно добавить запись в конфигурационный файл **`/etc/fstab`**. Он позволяет настроить параметры, такие как точка монтирования, тип файловой системы и другие опции.
*   **Безопасное извлечение**: Перед физическим отключением диска в Linux необходимо выполнить размонтирование командой `umount`.
